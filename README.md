# 🎓 Green University 프로젝트

Java/JSP 기반의 대학교 홈페이지 팀 프로젝트입니다.

---

## 📖 프로젝트 개요

**Green University 프로젝트**는 HTML, CSS, JSP를 활용하여  
대학교 홈페이지의 사용자 화면과 관리자 화면을 구성한 웹 프로젝트입니다.

---

## ✨ 주요 기능

### 👤 사용자 기능

- 메인 페이지
- 학사 안내 페이지
- 대학/학과 소개 페이지
- 커뮤니티 페이지
- 회원가입

### 🛠 관리자 기능

- 관리자 메인 화면
- 학생 관리 화면
- 학과 관리 화면
- 강의 관리 화면
- 교수 관리 화면

---

## 🧑‍💻 담당 역할

본 프로젝트에서 저는 **관리자 파트 화면 구성과 회원가입 기능**을 담당했습니다.

### 담당 기능

- 관리자 파트 HTML/CSS 화면 틀 구현
- JSP 기반 회원가입 화면 구현
- 회원가입 입력 데이터를 데이터베이스에 저장하는 기능 구현
