# 🎓 GreenUniversity

BNK 부산은행 금융DT 아카데미 미니 1차 프로젝트로 진행한 **JSP/Servlet 기반 대학 홈페이지 및 학사관리 웹 애플리케이션**입니다.

---

## 📌 프로젝트 개요

대학 소개, 입학 안내, 학사 안내 등의 정보를 제공하는 대학 홈페이지와 학생·교수·강의 정보를 관리하는 학사관리 시스템을 구현했습니다.

- **프로젝트 기간**: 2025.09.04 ~ 2025.09.12
- **프로젝트 형태**: 5인 팀 프로젝트
- **주요 목적**: JSP/Servlet 구조와 데이터베이스 연동 학습

## ✨ 주요 기능

### 대학 홈페이지

- 대학 소개 및 입학 안내
- 학사 안내 및 대학생활 정보 제공
- 커뮤니티 및 학생지원 서비스
- 로그인 및 회원가입

### 학사관리 시스템

- 학생 및 교수 정보 관리
- 대학 및 학과 관리
- 강의 등록 및 수강 현황 관리

---

## 👨‍💻 담당 기능

### 1. 학사관리 페이지 화면 구성

- 학사관리 페이지의 공통 화면 틀 구성
- 상단 헤더와 하단 푸터 제작
- 헤더와 푸터 사이에 각 관리 기능의 본문을 배치할 수 있도록 레이아웃 구성

### 2. 회원가입 및 DB 저장

- 회원가입 화면에서 입력한 사용자 정보를 서버로 전달
- Servlet에서 회원가입 요청 데이터 처리
- JDBC를 이용하여 회원정보를 Oracle Database에 저장
- 별도의 상세 유효성 검사는 구현하지 못했으며, 회원정보가 DB에 저장되는 단계까지 구현

---

## 💭 느낀 점

첫 팀 프로젝트를 통해 HTML로 구성한 화면이 Servlet과 JDBC를 거쳐 데이터베이스와 연결되는 전체 흐름을 경험할 수 있었습니다.

회원가입 정보를 데이터베이스에 저장하는 기능까지 구현했지만, 입력값에 대한 유효성 검사를 완성하지 못하면서 단순히 데이터가 저장되는 것뿐만 아니라 정확하고 안전한 데이터를 입력받는 과정도 중요하다는 것을 알게 되었습니다.

또한 GitHub와 Discord를 활용해 팀원들과 작업 내용을 공유하면서, 기능 구현뿐만 아니라 역할 분담과 지속적인 소통도 프로젝트 진행에 중요하다는 점을 배웠습니다.
